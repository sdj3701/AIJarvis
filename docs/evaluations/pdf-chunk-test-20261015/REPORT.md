# 제공 PDF의 자비스 청크 시험 — 2026-10-15

## 판정

**현재 자비스의 PDF 직접 등록은 미지원이다. 추출 텍스트의 분할 한도·누락 검사는 통과했지만,
법령의 조 구조까지 잘 보존한다고 판정하기에는 보완이 필요하다.**

대상: `건축기본법(법률)(제21065호)(20251001).pdf`. 6쪽, 121,450바이트.
PDF 해시: `b25f8073d1ecbb1dc268f322593e444af5cdf524aa2beee2d8949206c248ce11`.
최신 법령 여부나 법률 해석의 정확성을 판정한 시험이 아니라 제공된 파일의 처리 시험이다.

## 실행 범위

1. 원본을 격리된 시험 docs 폴더에 복사해 현재 DocumentIndexer.sync에 등록했다.
   결과는 `PDF 형식 미지원 (ValueError)`, 등록 문서 0개였다.
2. 번들 pdfplumber로 6쪽의 텍스트를 추출하고 pypdf와 교차 검사했다.
   공백·꼬리말 배치를 제외한 문자열은 6/6쪽 일치했다. OCR 없이 추출 가능했다.
   Poppler로 6쪽을 렌더링해 제목·조항·페이지 연결을 시각 확인했다.
3. 원시 추출 텍스트와 시험용 구조화 Markdown을 각각 별도 DB에 넣었다.
   실제 자비스 `recursive-context-v2`, embeddinggemma, FTS/벡터/RRF/재정렬 경로를 사용했다.
4. 이 파일에서 직접 고른 질문 9개로 조항과 정답 문자열을 함께 포함한 청크가 검색되는지 검사했다.
   기대 조항/정답은 점수 계산에만 쓰고 검색 입력에 주입하지 않았다.

운영 코드와 `D:\Jarvis-v2-dev`의 문서·색인은 수정하지 않았다. PDF 변환은 시험 스크립트에만 있다.

구조화 때 반복 머리말·꼬리말만 제거하고 제목 표시·빈 줄을 추가했다. 나머지 비공백 문자의 일치를 확인했다.
문자열/조항 범위를 이용한 자동 판정이며 법령 의미 전체의 자동 평가가 아니다.

## 실제로 발견한 문제

- 원시 청크 0(0부터 번호)은 제1조·제2조와 제3조 도입부를 함께 담는다.
  제3조의 정의 목록은 다음 청크로 넘어가지만 다음 청크의 제목은 파일명뿐이다.
- PDF 3→4쪽에 걸친 제14조는 원시 청크 10·11로 나뉘고, 다른 조와 섞인다.
  구조화 시험의 청크 22는 제14조의 1~8호 전체를 한 청크(235토큰)로 유지했다.
- PDF 5→6쪽의 제25조 첫 항은 원시 청크 17 안에서 `협의`와 `하여` 사이에 꼬리말·머리말이 끼었다.
  구조화 시험은 이 잡음을 제거했고, 제25조를 두 청크로 나누면서 둘 다 같은 조 제목을 메타데이터에 유지했다.
- 원시 청크 6은 개정일의 뒤쪽 `3. 23.>`부터 시작한다. 날짜의 마침표를 문장 경계처럼 다루는 문제가 있다.
- 구조화 시험에서도 장 제목·부칙 제목만 있는 청크 7개가 생겼다. 제목은 하위 조의 메타데이터로
  전달하되 본문 없는 검색 청크를 만들지 않는 개선이 필요하다.
- 구조화의 조 제목 보존은 본문 또는 색인 title 기준이다. 뒤쪽 청크의 본문에 조 제목이 반복되지는 않는다.
  현재 RetrievedChunk에는 title/page 전용 필드가 없어 생성 문맥·PDF 페이지 인용까지 이어지는 처리는 별도다.

순위는 자비스가 실제 반환한 순서이며 인접 청크 확장을 포함한다. `main`은 본문, `appendix`는 부칙이다.

실제 로컬 임베딩과 재정렬은 모든 질문에서 정상 작동했다. 구조화 시험은 첫 질문의 기대 근거가
1위에서 2위로 내려갔으므로 검색 정확도가 향상됐다고 주장하지 않는다. 이 9개는 한 문서에서
선택한 작은 점검 세트이며 다른 문서·질문에 일반화할 수 없다. LLM 최종 답변 생성은 이번에 측정하지 않았다.

## 후속 개발 권고

1. PDF 추출 단계에서 반복 머리말·꼬리말을 제거하고 페이지를 넘는 본문을 연결한다.
2. 법령의 장·조·항·호와 부칙을 구조 정보로 보존한 다음 현재 재귀 청크를 적용한다.
3. 조 번호·제목·페이지를 모든 관련 청크와 답변 근거까지 전달한다. 제목만 있는 청크는 검색에서 제외한다.
4. 개정일·조문 참조를 문장 경계로 오인하는 사례를 회귀 테스트에 추가한다.

시험 결과만 저장했으며 위 후속 기능은 운영 코드에 구현하지 않았다.
