## 이전 데이터 처리

- `D:\Jarvis-v2-dev`의 설정과 문서 색인을 기준으로 통합했다.
- `D:\Jarvis`의 고유 대화 12개·체크포인트 3개·측정 기록 72개를 현재 DB에 합쳤다.
  예산 집계는 서로 다른 기간을 추가하고 겹친 기간은 비용·토큰·요청 수를 합산했다.
- 이전 대화 원본·고유 모델·음성 프로필을 보존했다. 이전 로그는 `data/logs/prototype`에 모았다.
- 동일한 모델 파일 20개는 SHA-256으로 확인해 한 벌만 유지했다(837,491,427바이트 중복 제거).
- 구형 설정과 잠금·다운로드 캐시는 현재 설정으로 대체했다. 기존 백업 파일 9개는 요청에 따라 정리했다.
  `data/backups`는 향후 명시적 백업 기능이 사용하는 빈 작업 폴더다.
- 두 외부 데이터 폴더는 파일·DB·설정·검색 검증을 마친 뒤 Windows 휴지통으로 옮겼다.
  이전 경로는 더 이상 존재하지 않으며 실제 디스크 공간 회수는 휴지통을 비울 때 이루어진다.
  소스 체크아웃 `AIJarvis`와 `Jarvis-prototype`은 이번 두 데이터 폴더 통합 범위에 포함하지 않는다.
